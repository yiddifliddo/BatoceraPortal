Where Batocera expects artwork

        
/userdata/themes/<theme>/
  theme.xml
  <system>/
    theme.xml            per-system overrides
    art/logo.png         system logo (what this page uploads)
    art/background.png   optional background
/userdata/roms/<system>/
  gamelist.xml           metadata written by the scraper
  images/<rom>-image.png   screenshot
  images/<rom>-box.png     box art (2D)
  images/<rom>-marquee.png marquee / wheel
  videos/<rom>-video.mp4
